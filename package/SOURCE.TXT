F030SID source and upstream notices
==================================

The SID reference logic and sampled
waveform tables are derived from reSID
by Dag Lem and contributors.  reSID's
code is licensed under GNU GPL v2 or
later.  See COPYING.TXT and copyright
notices in the corresponding source.

Source and release downloads:
https://github.com/AnimaInCorpore/F030SID

Each binary release provides a
F030SID-SOURCE.tar.gz asset containing
the matching project source and reSID
source/data at the recorded revisions.
Build instructions are in README.md;
SOURCE-REVISION.TXT records dependency
revisions.  The separate build toolchain
is initialized as described there.

The Falcon player implements the SID
on its DSP; host-side reSID and
libsidplayfp tools verify its output
and register writes.  libsidplayfp is
fetched from its pinned source release
by the Makefile when needed.

The demo tune is generated by this
project.  Other SID tunes belong to
their respective authors and are not
included in this archive.
